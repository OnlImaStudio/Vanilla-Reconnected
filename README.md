Vanilla Reconnected

Minecraft, as it should be.

Vanilla Reconnected is a large-scale Minecraft mod currently in development.

The project focuses on systematically refining and reconnecting the vanilla experience. It aims to resolve awkwardness, bring conflicting rules into alignment, complete unfinished ideas, and improve the relationships between parts of the game that currently feel separated.

The goal is to make Minecraft feel more consistent, intuitive, and complete while preserving its identity.

Vanilla Reconnected has a broad and detailed design direction and is being implemented step by step. More of the project will be released as development progresses.

The project is guided by four main principles:

Keep rules coherent.
Make important rules readable.
Connect what already exists.
Preserve Minecraft's identity.
